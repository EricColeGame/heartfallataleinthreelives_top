## ベテランのようにダウンロード、インストール、トラブルシューティングする

ダウンロードページには複数のビルドがあるため、慎重に選んでください。Windowsの.exeはワンクリックで起動できますが、それ以外はすべて先に展開する必要があります。チームによると、ビルドはまだ公証されていないため、初回起動時にOSが安全警告を出すことがあります。macOSではGatekeeperを回避する必要があり、ページにはその手順のチュートリアルへのリンクがあります。

| プラットフォーム | ファイル | おおよそのサイズ |
|---|---|---|
| Windows | .exe（展開不要） | 2.1 GB |
| Windows | .zip（ダウンロードしやすい） | 801 MB |
| macOS | .zip | 833 MB |
| Linux | .zip | 689 MB |

| 手順 | 操作 | 重要な理由 |
|---|---|---|
| 1 | 自分のOS用ビルドをダウンロードする | 別OS用のファイルはそもそも起動しない |
| 2 | .zipを展開する（.exeの場合は不要） | アーカイブ内から実行するとエラーが発生する |
| 3 | 必要ならOSの安全プロンプトを回避する | ビルドが公証されていないため |
| 4 | 設定でコンテンツのトグルを調整する | 突然の音、点滅、明るい色、罵り言葉はすべて切り替え可能 |
| 5 | 複数のスロットにセーブする | コミュニティ報告では、リロードを強いられるソフトロックが報告されている |

ソフトロックと言えば、パッチ1.01はルート8のソフトロックを特に修正しました。開発者は、パッチ済みファイルが元のファイルを置き換えるだけだと確認しています。別のパッチボタンを探すのではなく、再ダウンロードする方式です。プレイヤー体験では、Joelルートの勧誘での停止、セーブが消えるバグ、真のフルスクリーンモードへの要望など、いくつかの粗さも依然として指摘されています。新しいiMacを使う一部のMacユーザーも起動失敗に遭遇しましたが、チームは修正をプッシュしたと述べています。実験する前に、必ずセーブフォルダのバックアップを取ってください。
