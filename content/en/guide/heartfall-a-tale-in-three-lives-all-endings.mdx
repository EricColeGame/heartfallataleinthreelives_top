## How the Route System Actually Works in Heartfall

Heartfall is structured in **sessions** — narrative chapters that each end with a cluster of decisions. Community reports consistently point to the same branch triggers: who you talk to first, whether you follow up on a second conversation, which alliance you commit to, and which quest step you complete before leaving an area. Because the game is session-based rather than chapter-select, a single missed conversation can quietly lock you into a different route than the one you intended.

That's the core frustration behind most "I keep getting the Scar route" posts. Players report that the game doesn't always signal when a branch has been committed, and autosave behavior can overwrite the moment just before the split. The result: two people making what feel like identical choices can land on completely different paths.

| Branch Factor | Why It Matters | What to Do |
|---|---|---|
| Conversation order | Talking to one character before another can set your alliance flag | Talk to everyone in an area before triggering the main objective |
| Repeat conversations | Some characters need a second, follow-up talk to fire the next event | Re-talk to key NPCs until dialogue starts repeating |
| Quest step order | Gathering certain materials first has caused softlocks on specific routes | Follow the quest log's listed order where possible |
| Session transitions | Autosaves happen at session boundaries | Manual-save at the start of every session |
| Exploration gating | "There is no point going this way" messages indicate a locked branch | If blocked everywhere, you've likely missed a flag |

## A Practical Checklist for Unlocking Every Ending

Use this sequence for each new route attempt. It's built from patterns that show up repeatedly in player reports.

1. **Start a fresh save slot** and name it after the route you're targeting (e.g., "FH Run 2").
2. **Exhaust all dialogue** in the opening area before touching the main quest marker.
3. **Re-talk to your primary ally** after the first quest update — several branches need that second conversation.
4. **Save manually at the start of every session**, before making any choice.
5. **Keep two rotating saves per route** so you can step back one session without losing the whole run.
6. **Read the quest log literally** and complete objectives in the listed order.
7. **Note any "blocked path" message** — it usually means a flag hasn't fired, not that the area is locked forever.

## Save Slots, Patches, and Softlocks That Block Endings

Nothing kills an ending run faster than a corrupted or deleted save. Community reports describe a specific hazard: choosing "no" when asked to clear save files has still wiped all saves for some players. Others have lost progress to softlocks where an NPC vanishes or a scene loops the same line.

The recovery method that players share most often is Windows' file history. Godot-based games typically store save data under your user profile's app data folder; restoring a previous version of that folder can bring back `data.globaldata` and the individual save files. Back up the real folder first, then copy the restored files back in.

| Reported Problem | Where It Happens | Community Workaround |
|---|---|---|
| All saves deleted after declining a clear | Save management menu | Restore a previous version of the Godot app data folder |

## Tips for a Cleaner Ending Run

- **Don't play tired.** The game hides flags in casual dialogue, and a skipped line can cost a whole route.
- **Write down what you chose.** A simple notes file with session number, ally, and quest order makes repeat runs much faster.
- **Expect emotional whiplash.** Players consistently describe the routes as heavy; the game's content warnings are listed in the in-game info menu and include spoilers, so read them before diving in.
- **Use the toggle settings.** Flashing, bright colors, sudden noises, and swearing can all be adjusted, which makes long ending-hunting sessions much easier.
- **Be patient with bugs.** This is a large fan project with an active patch history; if a route breaks, check whether a newer build exists before restarting.

## FAQ: Heartfall A Tale in Three Lives All Endings

**How many endings does Heartfall have?**
The developers describe "many story routes" rather than a fixed number, and no official ending count has been published. Community trackers list at least eight distinct routes, including the canon 3rd Life path, the Desert Duo route, Flower Husbands, and a hidden Watchers storyline.

**Can I get Heartfall A Tale in Three Lives all endings in one playthrough?**
No. Routes contradict each other and lock out alternative alliances, so you'll need multiple saves or multiple playthroughs. Plan one route per save slot and keep a backup.

**Why do I keep landing on the Scar route instead of Flower Husbands?**
Player experience suggests the Flower Husbands branch requires specific conversation flags early on, and missing them routes you toward Scar by default. Exhaust dialogue with Scott and Jimmy, re-talk after quest updates, and save before each session transition.

**Is the Watchers dialogue actually decodable?**
Players have asked this repeatedly without a confirmed answer. Some report unlocking "Watcher stuff" naturally on a first run; whether the in-game text is a real cipher remains an open question in the community.
