## How Heartfall's Route System Actually Works

Every route diverges hard. The store description promises you might become a detective, cheat on your first alliance, or uncover secrets best left forgotten. Progress is tracked in "sessions," and deaths are fatal-but-temporary, so a bad session rarely ends a run — it just reshapes it.

Community members have mapped a few route numbers by name, which helps when you are trying to steer toward or away from a branch.

| Route | Focus (community-reported) | Notes |

That last row is the key caveat. No official numbering for Watcher content appears in the store page or patch notes, so treat any specific "Route X = Watchers" claim as player experience rather than fact.

## Save Discipline Makes or Breaks Any Watcher Run

The most common mistake players make in any **Heartfall A Tale in Three Lives Watcher route guide** attempt is treating saves casually. Heartfall is a Godot game, and on Windows its save data lives in a Godot app data folder under your user profile — community members have documented restoring lost progress by right-clicking that folder and using "Restore Previous Version."

That trick works because Windows keeps automatic backups. It is not a substitute for discipline, though.

| Habit | How to do it | Payoff |
|---|---|---|
| Rotate slots | Use 3+ saves, cycling each session | One corrupted or softlocked save never ends the run |
| Name saves by route | "Watcher attempt 2 – Session 4" | You can compare branches without replaying |
| Back up the folder | Copy the Godot app data folder before big sessions | Protects against the save-clearing bug |
| Avoid the delete menu | Never use in-game "clear saves" while other runs exist | Reported to delete more than intended |
| Keep one "clean" save | Freeze a slot at the branch point you care about | Lets you test choices quickly |

One community member lost every slot after trying to remove a single save and confirmed the files were not in the recycle bin. They recovered them only through the Windows previous-version method. Back up first, experiment second.

The store page describes "many" routes with 12+ characters and wildly divergent outcomes. Community members reference at least eight numbered branches plus named paths like Flower Husbands, Joel, and Cow Heist.

No. The game explicitly states that no prior knowledge is required, and the Watcher thread is original lore built around the cast rather than a retelling of the SMP.
