A few practical notes from player experience:

- **Never run the game from inside the zip archive.** Extract first, or saves and assets may fail to load.

## Troubleshooting the Heartfall A Tale in Three Lives Download

The most valuable thing you can do before your first session is simple: **use multiple save slots**. Community reports over the first weeks of release show a consistent pattern of players losing progress to softlocks or a save-clearing bug, and a backup slot is the only reliable insurance.

| Reported Issue | What Happens | Workaround |
|---|---|---|
| Save files vanish | Deleting one save clears all of them | Restore previous versions of the Godot app data folder |
| Route softlocks | Dialogue repeats and no new objective appears | Reload an earlier save from a different slot |
| Missing character on a recruitment route | An NPC doesn't spawn where expected | Replay the preceding conversation fully before moving on |
| No fullscreen option | Window can't be maximized as expected | Check display settings; feature has been requested |
| Lag or stutter | Frame drops during busy scenes | Close background apps; lower settings if available |

For the save-loss issue, players on Windows have had success restoring a previous version of the Godot user data folder, which lives under `AppData\Roaming\Godot\app_userdata` in your user directory. Right-click the folder, choose "Restore Previous Version," and copy the backed-up save files into the live folder. **Back up the current files first** — this is a recovery method, not a guaranteed fix.

It's also worth noting that softlocks have been patched before. A known softlock on one of the later routes was fixed in a version 1.01 update, which is exactly why re-downloading the latest build should be your first troubleshooting step rather than your last.
